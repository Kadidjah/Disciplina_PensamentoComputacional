Tratamento de Erros - Conteúdo Completo

Erros de sintaxe ocorrem quando o código viola as regras da linguagem de programação.

Exemplo: 
def saudacao(nome)  # ❌ Falta de dois-pontos
    print("Olá, " + nome)
Solução: 
def saudacao(nome):  # ✅ Correto
    print("Olá, " + nome)

O código executa sem erros, mas produz resultados inesperados.

Exemplo: 
if numero % 2 == 1:  # Verifica ÍMPARES, não pares!
    print("Número par")
Solução: 
if numero % 2 == 0:  # ✅ Verifica PARES
    print("Número par")

O código é válido, mas causas uma exceção durante a execução.

Exemplo: 
resultado = 10 / 0  # ❌ ZeroDivisionError!
Solução: 
try:
    resultado = 10 / 0
except ZeroDivisionError:
    print("Não é possível dividir por zero")

🎓 Como Resolver?

  1. Leia o enunciado com atenção
  2. Entenda o erro ou problema
  3. Escreva a solução no editor
  4. Teste com diferentes entradas
  5. Compareà solução comentada
  6. Refatore e otimize

💡 Dicas Importantes

  • Use print() para debug
  • Teste casos extremos
  • Valide entradas do usuário
  • Use try/except para erros
  • Comente seu código
  • Reutilize funções

ℹ️ Sobre a Disciplina

Objetivo

Esta disciplina tem como objetivo desenvolver o pensamento computacional, ensinando aos alunos como resolver problemas complexos usando lógica, algoritmos e estruturas de dados.

O que você vai aprender?

  • ✅ Identificar e corrigir erros de programação
  • ✅ Desenvolver algoritmos eficientes
  • ✅ Usar estruturas de dados apropriadas
  • ✅ Escrever código limpo e bem documentado
  • ✅ Resolver problemas de forma lógica
  • ✅ Trabalhar em equipe e colaborar

Duração

12 semanas com atividades semanais e projetos práticos.

Avaliação

Baseada em desafios práticos, projetos finais e participação nas atividades.
